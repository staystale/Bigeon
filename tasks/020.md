Goal: on Windows, a restart stops the real leftover agent. Today the marker only holds the cmd.exe wrapper pid, which is
gone after a crash while node agent.js and its children keep running (see result 019). Fix: record the agent's whole
process tree while it runs.

2. src/worker.ts:
   a. Marker gets "agentPids": number[] (default [] when reading). writeMarker takes it too; keep everything else as is.
   b. Windows only (process.platform === 'win32'), in runAgent while the child runs: every 3 s, asynchronously
      (execFile, never spawnSync) run powershell.exe -NoProfile -NonInteractive -Command
      "Get-CimInstance Win32_Process | ForEach-Object { \"$($_.ProcessId) $($_.ParentProcessId)\" }".
      In JS, collect all descendants of child.pid. If the set changed, call a new callback onTree(pids: number[]) that
      rewrites the marker with agentPids. Ignore powershell errors. Stop the timer when the child exits, and ignore any
      snapshot that finishes after the child exited (it must never recreate the marker after the task is done).
      Do the first snapshot 1 s after spawn.

      [agentPid, ...agentPids] that isRunning, each with killPid, ignoring errors. If any was stopped, log once:
      `[bigeon] stopped leftover agent ${pids.join(', ')} from an interrupted run`. Machine-restarted log unchanged.
