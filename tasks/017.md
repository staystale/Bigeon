Goal: task 015a. Only one worker loop per folder, and a restart stops any agent left over from a crash.
Steps:
1. git fetch origin, then: git checkout -b worker/017 origin/main
2. src/worker.ts:
   a. Lock. At the start of runWorker, before the loop: lockPath = .bigeon/worker.lock (create .bigeon if needed).
      If the file exists and holds {"pid": N} and N is running (process.kill(N, 0) does not throw), throw
      new Error(`another bigeon worker is already running in this folder (pid ${N})`).
      If N is not running (or the file is unreadable), log '[bigeon] took over a stale lock'.
      Then write {"pid": process.pid}. Remove the lock in a finally block around the whole loop, and in
      process.once('SIGINT') / process.once('SIGTERM') handlers that remove it and call process.exit(130).
      Remove those handlers in the finally block (process.off), so tests that call runWorker do not leak them.
   b. Leftover agent. The in-progress marker becomes {"id": "<id>", "agentPid": number | null}.
      Give runAgent an onSpawn(pid: number) callback; when it fires, rewrite the marker with agentPid.
      readMarkerId keeps working (also read agentPid). When a task starts and the marker has an agentPid,
      call the existing killTree logic on that pid (make a small killPid(pid) helper next to killTree and reuse it in
      killTree, do not duplicate the taskkill code), ignore errors, and log
      `[bigeon] stopped leftover agent ${pid} from an interrupted run`.
3. Tests in test/recover.test.ts (reuse test/helpers.ts; add a helper there only if it is used twice):
   a. 'a second worker in the same folder refuses to start': write .bigeon/worker.lock with {"pid": process.pid}.
      worker --once exits non-zero and stderr matches /already running/.
   b. 'a stale lock is taken over': lock with {"pid": 999999}. worker --once with a quick agent exits 0 and stdout
      matches /took over a stale lock/. Afterwards .bigeon/worker.lock does not exist.
   c. 'a leftover agent from a crash is stopped on restart': the crashing agent spawns a hanging grandchild, writes
      grandchild.pid, then started.txt, then hangs. crashWorker as today. Then worker --once with a quick agent:
      stdout matches /stopped leftover agent/, and the grandchild pid is gone within 5 s (same polling as the timeout
      test; if still running, kill it and fail).
